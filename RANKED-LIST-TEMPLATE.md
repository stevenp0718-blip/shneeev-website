# Ranked guide video template

Paste this block anywhere in the YouTube description for a Top 5, buying guide, or other ranked video. The website updater will create a separate guide page and add it to the homepage and search results automatically.

```text
SHNEEEV LIST
Title: Top 5 Most Anticipated Mice of 2026
Intro: The five upcoming mice I am most excited to try in 2026.
Category: Mouse Guide

Item 1 Name: Mouse name
Item 1 Link: https://official-product-link.com/
Item 1 Price: $000.00
Item 1 Note: Why this mouse made the list.

Item 2 Name: Mouse name

END SHNEEEV LIST
```

## Rules

- Use `SHNEEEV LIST` for ranked guides and the existing review block for product reviews.
- `Item # Name` is required. Links, prices, and notes are optional.
- Purchase links must begin with `https://`.
- One to ten ranked items are supported.
- If a product is not available yet, leave its Link and Price lines out. The page will show “Purchase link coming soon.”
- Ranked-guide pages include the current non-affiliate disclosure automatically.
